# Filtros de classificação por id (manual 6.6, p.28)

Operações para filtros com id: `igual` e `diferente`.

| Filtro | Descrição |
|---|---|
| `ramo de atividade igual("1", "12")` | id do ramo de atividade igual a um dos valores |
| `código da rota diferente("4", "7", "14")` | código da rota diferente dos valores |
| `id do cliente igual(...)` | ID(s) específico(s) do cliente |
| `id do cliente principal diferente(...)` | id do cliente principal diferente do informado |
| `tipo de pagamento igual(...)` | id de pagamento igual a um dos valores |
| `tipo de cobranca diferente(...)` | id de cobrança diferente dos valores |
