# Opções de tempo e condicionais de tempo (manual 6.11.1, 6.11.2, 6.12, 6.13, p.33-37)

## Tempo (valorado)
Referencia um período: `<N> anos`, `<N> semestres`, `<N> trimestres`, `<N> bimestres`, `<N> meses`, `<N> semanas`, `<N> dias`.

## Tempo fixo (períodos pré-definidos, sem valor)
`do dia`, `na semana`, `na quinzena`, `no mês`, `no bimestre`, `no trimestre`, `no semestre`, `no ano`, `de ontem`, `na semana anterior`, `na quinzena anterior`, `no mês anterior`, `no bimestre anterior`, `no trimestre anterior`, `no semestre anterior`, `no ano anterior`.

## Condicionais de tempo
| Condicional | Descrição |
|---|---|
| `em <N> anos` / `semestres` / `trimestres` / `bimestres` / `meses` / `semanas` / `dias` / `horas` / `minutos` | dentro do intervalo especificado |
| `há <N> anos atras` / `semestres` / `trimestres` / `bimestres` / `meses` / `semanas` / `dias` | intervalo anterior à unidade especificada |
| `na manhã` / `na tarde` / `na noite` | dentro da parte do dia |
| `no dia` | dia atual |
| `ontem` | o dia de ontem |
| `na semana` / `na quinzena` / `no mês` / `no bimestre` / `no trimestre` / `no semestre` / `no ano` | o período atual |
| `entre <tempo> e <tempo>` | intervalo de tempo definido |
| `entre <data> e <data>` | intervalo de datas |

Exemplo: `recencia de visita entre 10 dias e 90 dias`.

## Condicionais para tempo futuro ou intervalo no passado
| Condicional | Descrição |
|---|---|
| `nos proximos <N> anos` / `semestres` / `trimestres` / `bimestres` / `meses` / `semanas` / `dias` / `horas` / `minutos` | entre agora e N unidades à frente |
| `em <N> anos a frente` / `semestres` / `trimestres` / `bimestres` / `meses` / `semanas` / `dias` | período que começa após N unidades à frente |
| `de ontem` | somente o dia de ontem |
| `na semana anterior` / `na quinzena anterior` / `no mês anterior` / `no bimestre anterior` / `no trimestre anterior` / `no semestre anterior` / `no ano anterior` | somente o período anterior |

`<data>`: `'yyyy-mm-dd'` ou `'dd-mm-yyyy'`.
