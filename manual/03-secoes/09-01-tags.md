# Tags de clientes (manual seção 9, p.55-56)

Tags marcam clientes para facilitar filtros, segmentações e análises. Dois tipos:
- Tag de contexto: marcação baseada numa condição (gatilho) sobre os clientes.
- Tag nomeada: marcação baseada numa tag de contexto já criada, com texto descritivo.

Tag na linguagem: `@nometag`, só letras minúsculas e números (exemplos `@ruptura`, `@inativo`). Os gatilhos de tags são distintos dos de alertas.

## Gatilhos de tags de contexto
| Gatilho | Descrição |
|---|---|
| `tem produtos e <filtro de produtos>` | tem produtos que atendem ao filtro |
| `tem produtos sugeridos e <filtro de sugestão>` | tem sugestões de produtos |
| `tem fornecedores e <filtro>` | tem fornecedores que atendem ao filtro |
| `tem fornecedores sugeridos e <filtro>` | tem sugestões de fornecedores |
| `tem rotas` | pertence a alguma rota |
| `tem cidades` | está em alguma cidade cadastrada |
| `tem estados` | pertence a algum estado |
| `tem ramo de atividade` | tem ramo de atividade definido |
| `tem classificacao` | tem classificação definida |
| `tem plano de pagamento` | tem plano de pagamento |
| `tem plano de cobrança` | tem plano de cobrança |
| `tem feedbacks e <filtro de feedback>` | tem feedbacks de atendimento no período |

## Filtros de produtos
| Filtro | Descrição |
|---|---|
| `recencia de venda entre <N> dias e <M> dias` | produtos com venda recente no intervalo |
| `não tem venda em <N> dias` | produtos sem venda há N dias |
| `em ruptura` | sugestões de produto do tipo ruptura |
| `no momento certo` | sugestões do tipo "momento certo" |
| `mais vendidos` | sugestões dos produtos mais vendidos |
| `primeira compra` | sugestões para primeira compra |
| `skus não vendidos` | SKUs que o cliente ainda não comprou |
| `prioritarios` | produtos prioritários |
| `todas as sugestões` | todos os tipos de sugestão |

## Filtros de feedbacks
| Filtro | Descrição |
|---|---|
| `no ultimo atendimento` | no atendimento mais recente |
| `nos ultimos <N> atendimentos` | nos N atendimentos mais recentes |
| `aparece <N> vezes nos ultimos <M> atendimentos` | aparece N vezes nos últimos M atendimentos |
